### PR 栈自动驾驶

执行 Autopilot-full（完全自动驾驶） 操作手册，但不合并。

1. **用“验证通过即停”替代第 5 步。** 每个 PR 在当前 head 上通过验证且全绿后停止，再把 PR 交给操作者。交接后，没有操作者许可，任何人都不推送。每次循环心跳的提示词都写明本文件，让每轮都能看到禁止合并的规则。
2. **仅当 PR 基于另一个 PR 时才堆叠。** 这是第 3 步唯一的例外。按 `playbooks/opening-a-pr.md` 的“大小与 PR 栈”，把 PR 基于另一个 PR 的分支，而非主干。用各 PR rebase 到父 PR 分支、栈根 rebase 到主干，替代第 2 步的 rebase 到主干。下层 PR 的新 head 会使上方 PR 重新堆叠；重新堆叠后 `git patch-id` 不变的 PR 保留原裁决。

**回复：** 列出每个 PR 及其裁决，替代已合并内容。
