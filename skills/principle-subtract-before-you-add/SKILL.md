# 先减后加

演进系统时，先去除复杂性，再构建。默认做减法。

持续投入简化。离开时，让相同或更小接口背后的设计比接手时更简单、更有能力。

- 安排先删除后构建
- 先删减后打磨，先到最小规模，再投入质量
- 根据已观察用法设计，不为推测性边界情况设计
- 不添加规范要求之外的推测性校验器、解析器或防护
- 简化提示词，移除冗余指令和过多模板
- 引用材料没有新内容时，删除它，不留空壳
