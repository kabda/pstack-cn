# Slack 会话

<a id="how-to-search-it"></a>
## 如何搜索

Slack MCP 工具各不相同。先检查可用的是哪个 Slack MCP，并查看其工具 schema。它可能需要 `mcp_auth`。如果身份验证失败，停止并报告缺口。

1. **限定作者搜索。** 搜索 PR 合并日期前后 PR 作者的消息。这样能大幅缩小范围，且常能找到关键内容。
3. **搜索 PR URL。** 审查或讨论 PR 时，Slack 中常有其链接。搜索 PR URL（或仅 `/pull/<number>`）。
4. **搜索错误字符串。** 如果代码处理某个特定错误，搜索该错误字符串，常能发现事故线程。

<a id="common-pitfalls"></a>
## 常见陷阱

- **频道考古限制。** 非常旧的消息可能因保留政策而消失。如果某日期之前什么也找不到，说明这个保留截止点。
- **未搜索的私信。** 许多决策在不可搜索的私信中发生，你会遗漏它们。这是已知限制。
- **把随口玩笑当成“决策”。** Slack 很随意。“哈哈，直接做吧”不算决策，即便它出现在提交之前。寻找经过思考的讨论。
- **单条消息丢失上下文。** 没有线程时，单条消息的含义常与上下文中不同。始终获取线程。
- **身份验证失败。** MCP 未认证时应停止。不要编造发现。报告无法搜索 Slack。
