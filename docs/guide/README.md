# pstack 指南

当你不再事无巨细地控制智能体时，pstack 才能发挥最佳效果。你说明想要什么，以及如何判断任务完成；`/poteto-mode` 选择操作手册，在各步骤需要时运行其他技能，并向你展示证据。本指南用贴近实际的提示词，帮助你养成这种习惯。

你将学到：

1. [设置 pstack](./01-setup.md)。安装插件并选择模型。
2. [通过 `/poteto-mode` 分派工作](./02-poteto-mode.md)。给它一个目标，观察它如何选择操作手册。
3. [理解代码](./03-understand.md)。先进行只读调查，在修改任何内容前使用 `/how`、`/why`、`/teach` 和 `/recall`。
4. [设计改动](./04-design.md)。在代码定型前，使用 `/architect`、`/arena`、`/swarm`、`/interrogate`、原型和计划。
5. [构建并清理改动](./05-build-and-clean.md)。构建操作手册、`/tdd`、`/unslop` 和 `/no-comments`。
6. [验证并交付](./06-verify-and-ship.md)。在真实应用上证明行为，形式化验证测试很少覆盖的情况，用 `/benchmark-checklist` 审核数字，然后创建范围集中的 PR 并推进到合并。
7. [在你睡觉时继续工作](./07-overnight.md)。先建立信任再运行循环，制定通宵运行约定，保留可审计的决策日志，并通过 Projects 和自动化扩展到多个智能体。
8. [用原则名称引导工作](./08-principles.md)。24 个名称，让你在任务中途调整智能体方向。
9. [按需定制](./09-make-it-yours.md)。自定义模式、用 `/correct` 纠正反复出现的错误，以及如何测试技能改动。
10. [实用配方与常见陷阱](./10-recipes-and-pitfalls.md)。可复制的提示词和应避免的错误。

首次阅读请按顺序进行。此后，各页均可独立查阅。

遇到困难，或不知道哪项技能合适时，输入 [`/poteto-help`](../../skills/poteto-help/SKILL.md) 并附上问题：

```text
/poteto-help 我应该用哪项技能审查这个分支？
```

它会回答问题，给你一条可发送的提示词，并链接到答案所依据的技能或指南页面。它不会开始执行工作，因为 pstack 的运行会消耗实际的 token；准备好后，由你发送提示词。它只在你输入时运行。

<a id="if-you-only-remember-one-thing"></a>

## 如果只记住一件事

用自己的话告诉智能体目标及检查方式：

```text
/poteto-mode 重试在运行中途到来时，导出会写入重复行。先复现，再修复并验证。
```

不必指定操作手册或列出技能。“先复现”和一个可检查的结果，就足以让 `/poteto-mode` 路由任务。它会匹配缺陷修复操作手册，把步骤复制到待办列表，并在每一步执行时调用合适的技能。
